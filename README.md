# ATM-Transaction-Analysis

Applied SQL and Excel for data cleaning and transformation of large ATM transaction datasets. Used Python for statistical analysis and machine learning to detect patterns and anomalies. Developed Power BI dashboards to visualize trends, fraud detection, and customer behavior, enhancing skills in data analysis, visualization, and fraud detection.

## Added UI Artifact

This repository now includes a standalone React component, `UmeshPortfolio.jsx`, that implements a single-file, cosmic-themed portfolio experience for **Umesh Kumar** using **React + Framer Motion + Tailwind + lucide-react**.

It includes:
- Animated star field and nebula-style background
- Scroll progress bar with `mix-blend-difference`
- Floating AstroGuide (inline SVG astronaut) with section-aware speech updates
- Hero, tech marquee, experience timeline, services spotlight cards, deployed systems cards, and contact/footer sections

To use it, import and render `UmeshPortfolio` inside an existing React/Tailwind project with the required dependencies.
